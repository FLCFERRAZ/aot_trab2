# Installation
## Prerequisites
Arduino IDE installed on your computer
Basic understanding of binary arithmetic and digital logic
Familiarity with Arduino programming
## Installation
Clone or download this repository
Open the 4_bit_adder.ino file in Arduino IDE
Connect your Arduino board to the computer
Wire the circuit according to the connection details
Upload the sketch to your Arduino

-> Download the "UnoArduSimV2.9.2.zip" file and unzip it to a folder;
-> Download the "base_trab_2.ino" file and save it to a folder (suggested name is "Trabalho 2");
-> Download the "ino_config.txt" file and save it to the same folder as the previous file;
-> Download the "myArduPrefs.txt" file and save it to the same folder as the previous file;
-> Open the Arduino simulator and open the "base_trab_2.ino" file;
